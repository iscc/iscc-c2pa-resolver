C2PA Soft Binding Resolution API · io.iscc.v0

Recover lost Content Credentials by content

A C2PA Manifest gets lost when a platform strips metadata or re-encodes a file. This service finds it again: send the ISCC of the file, and it searches the ISCC Discovery Protocol for declarations of similar content whose gateway URL is the address of a C2PA Manifest.

Check a file

Read and validate its Content Credentials, then search for lost ones.

Runs in your browser. Nothing is uploaded unless you ask for a search.

Testnet. This instance searches the ISCC testnet. Declarations here are for testing.

Experimental (beta, MVP). Provided as is, without warranty of any kind. The API, the gateway contract and the public instances may change in breaking ways before version 1.0.

Routes

RoutePurpose
GET /v1/matches/byBindingFind manifests for an io.iscc.v0 value
POST /v1/matches/byBindingSame query with a JSON body
GET /v1/manifests/{manifestId}Fetch a manifest returned in the last hour
GET /v1/services/statusOperational status
GET /.well-known/c2pa-soft-binding-resolutionService discovery

Every match carries an endpoint: $HOST/v1/iscc/{isccId}, with the ISCC-ID of the matched declaration in lowercase and without the ISCC: prefix. C2PA clients fetch the manifest from {endpoint}/manifests/{manifestId}, which has no time limit.

Query

The value is the base64 ISCC-SEQ of the asset, as specified in IEP-0020.

curl "$HOST/v1/matches/byBinding?alg=io.iscc.v0&value=<percent-encoded value>"

Matches are candidates. Confirm a match, for example by comparing the claim thumbnail with the asset, and validate the recovered manifest as usual.
